# 3D ENGINE CUBES

3D-движок для работы с трехмерной кубической графикой, анимацией и рендерингом сцен.

## 📌 Описание проекта
Проект разработан для генерации, анимации и отображения объектов в трехмерном пространстве.
Он позволяет создавать и быстро просчитывать 3D-структуры из кубов прямо в среде Scratch/TurboWarp.
Движок обеспечивает плавную отрисовку, анимацию объектов и полноценную визуализацию сцены.

## 💻 Минимальные требования
* **Среда запуска:** Браузер с поддержкой WebGL или десктопное приложение TurboWarp
* **Платформа:** TurboWarp (стандартный плеер Scratch не рекомендуется из-за ограничений по скорости)
* **Минимальная частота кадров:** **50 FPS** (при FPS ниже 50 возможны задержки и лаги)
* **Целевая частота кадров:** **60 FPS** (для максимально плавного рендеринга)
